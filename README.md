# Счётчик ковров на погрузке — демо-стенд

Статическая страница. Она проигрывает запись погрузки с трёх камер синхронно и показывает
поверх результат платформы подсчёта:
- рамки ленты и рулонов;
- какая камера сейчас считает и почему остальные нет («перекрыта», «ленты не видно»);
- накопленный счёт, ход погрузки и засчитанные рулоны.

## Что настоящее, а что смоделировано

**Настоящее.** Детекция (YOLOE по образцу), трекинг (ByteTrack), подсчёт и выбор камеры.
Это результат той же программы, что работает с камерами на объекте. Видео обработано
заранее, потому что на GitHub Pages нет сервера и видеокарты.

**Смоделировано.** Все три камеры получены из одной записи с телефона:
- камера 2 — тот же кадр, ближе и под другим углом;
- камера 3 — край склада без ленты;
- фура, закрывающая камеру 1 на 11–19 с, нарисована.

## Файлы

| Путь | Что |
|---|---|
| `index.html`, `style.css`, `app.js` | Дашборд без внешних зависимостей |
| `data/run.json` | Покадровый результат (10 кадров/с): статусы камер, рамки, засчитанные рулоны, переключения |
| `data/thumbs/` | Кадры засчитанных рулонов |
| `video/` | Записи камер (H.264) |

`data/run.json` создаётся скриптом платформы `tools/export_stand.py`.
